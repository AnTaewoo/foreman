| 목표 밖 Task("Refactor to Blueprints (optional)") | 분해 | AC 밖 허용 | "optional/refactor 금지, AC에 기여하는 Task만" |
| 모델이 쓴 테스트가 공유 store id를 가정해 3회 실패 | 분해+코딩+재시도 | spec에 기대값이 없고, 시스템 프롬프트가 테스트 상태를 말하지 않으며, 재시도가 진단 없이 "고쳐라" | spec에 테스트 기대값·fresh state 명시; 시스템 프롬프트 fresh state; 재시도는 "테스트 vs 코드" 진단 먼저 |
| `from src.app…` import, 없는 API 호출 | 코딩 | (PC-4에서 해결: 관련 파일·형제 파일) | 유지 |
