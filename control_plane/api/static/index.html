Goal 한 문장 → AI 에이전트 팀이 Plan → Issue → 브랜치 → PR을 만들고, 사람은 Plan 승인과 PR 머지만 합니다. 모든 상태 변화는 서명된 이벤트 체인으로 남습니다.

대상 GitHub repo ↗ API 문서 ↗ 소스 ↗
  1. Goal 만들기 — 아래 예시 버튼 하나를 누르고 "Goal 생성". 1~3분 뒤 Plan이 올라옵니다(로컬 LLM).
  2. Plan 승인 — Plan 본문을 읽고 Approve. 그러면 Task가 GitHub Issue로 만들어지고 워커 컨테이너가 코드를 씁니다.
  3. PR 확인 — Task마다 draft PR 링크가 생깁니다. PR 머지는 repo 소유자가 GitHub에서 합니다(사람 승인 지점). 머지되면 Task가 done이 되고 다음 Task가 배정됩니다.
