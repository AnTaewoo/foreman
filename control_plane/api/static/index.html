Goal 한 문장 → AI 에이전트 팀이 Plan → Issue → 브랜치 → PR을 만들고, 사람은 Plan 승인과 PR 머지만 합니다.

대상 GitHub repo ↗ API 문서 ↗ 소스 ↗
사용 방법 (3단계)
  1. Goal 만들기 — 만들 기능을 한 문장으로 적고 "Goal 생성". 잠시 뒤 Plan이 올라옵니다.
  2. Plan 승인 — Plan 본문을 읽고 Approve. Task가 GitHub Issue로 만들어지고 워커 컨테이너가 코드를 씁니다.
  3. PR 머지 — Task마다 draft PR이 생깁니다. 머지는 repo 소유자가 GitHub에서 합니다. 머지되면 Task가 완료되고 다음 Task가 배정됩니다.
