Foreman · 데모

만들 기능을 한 문장으로 적으면 AI가 Plan → Issue → 코드 → PR까지 만듭니다. 사람은 Plan 승인과 PR 머지만 합니다.

대상 GitHub repo ↗ API 문서 ↗ 소스 ↗
사용방법 6단계
  1. 내 GitHub 저장소를 준비합니다 — AI가 코드를 써 넣을 곳입니다. 새로 만든다면 GitHub의 New repository 화면에서 Add a README file에 체크하세요. 파일이 하나도 없는 빈 저장소는 연결되지 않습니다. 이미 쓰던 저장소가 있으면 그걸 써도 됩니다.
  2. Foreman 앱을 그 저장소에 설치합니다 — 아래 내 GitHub repo 연결을 펼치고 ① GitHub App 설치를 누릅니다. GitHub 화면이 열리면 Only select repositories에서 1단계의 저장소만 고르고 Install. AI가 그 저장소에 Issue·브랜치·PR을 만들 권한을 받는 단계입니다. 다른 저장소는 건드리지 않습니다.
  3. 저장소를 연결합니다 — 이 화면으로 돌아와 ② repo 칸에 내아이디/저장소이름을 적고 점검을 누릅니다. 목록이 초록 ✔이면 연결을 누릅니다. 노란 △는 경고일 뿐이라 그냥 연결해도 됩니다. 빨강 ✘이면 1·2단계를 다시 확인하세요.
  4. 만들고 싶은 것을 한 문장으로 적습니다 — 새 Goal 칸에 적고 Goal 생성을 누릅니다. 뭘 적을지 막막하면 예시 Goal을 눌러 그대로 써 보세요. 한 번에 기능 하나 정도가 가장 잘 됩니다. 1~3분 뒤 AI가 만든 Plan(작업 계획)이 아래에 올라옵니다.
  5. Plan을 읽고 승인합니다 — 계획이 괜찮으면 Approve를 누릅니다. 버튼 대신 안내문이 보이면, GitHub에 올라온 Plan 글에 /approve라고 댓글을 다세요. 같은 효과입니다. 승인해야 작업이 시작됩니다. 내용이 마음에 안 들면 Reject로 이 Goal을 접고 문장을 바꿔 다시 만드세요.
  6. PR을 확인하고 머지합니다 — 작업마다 PR(코드 변경 제안)이 생깁니다. GitHub에서 Files changed로 내용을 보고 괜찮으면 Merge pull request를 누르세요. 머지는 저장소 주인만 할 수 있습니다. 하나 머지할 때마다 다음 작업이 시작되고, 전부 끝나면 Goal이 완료가 됩니다.
